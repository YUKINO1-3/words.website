# VocabFlow AI

可选 [Cloudflare Workers + D1 部署](docs/deploy/cloudflare-d1.md)：前端和 API 同域运行，每位部署者使用自己的 Cloudflare 账号、D1 数据库和加密密钥。下文 Node/SQLite 流程仍可用于本地与服务器部署。

支持账号登录的英语与雅思词汇学习网站。React + Node.js + SQLite + ts-fsrs。每个账号拥有独立学习空间和加密保存的个人 AI 配置。

> 多用户升级：首次部署请先阅读 [登录系统升级与运维](docs/deploy/multi-user-login.md)。原单人数据需要管理员通过 CLI 指定归属；新注册账号不会自动获得原词库。默认安全 Cookie 需要 HTTPS；本地或临时 HTTP 测试显式设置 `AUTH_COOKIE_SECURE=false`。

## Windows 快速开始

本机开发和测试环境：**Windows、Node.js v24.17.0、npm 11.13.0**。安装 [Node.js 24 LTS](https://nodejs.org/)，安装时保留 npm 和 PATH 选项。项目路径可包含中文或空格。

1. 第一次双击 `首次安装.bat`：检查 Node 版本、创建不含密钥的 `.env`、按锁定文件安装依赖、构建前端。
2. 双击 `启动网站.bat`：启动服务，等待就绪后调用默认浏览器打开 **http://127.0.0.1:3000**。
3. 保留启动窗口。停止时在该窗口按 **Ctrl+C**。只关闭浏览器不会停止服务；停止服务后网站不可访问，重新启动可继续原有进度。
4. `配置向导.bat` 准备 `.env` 并在记事本中打开，可设置端口、数据路径和可选 AI。修改后重启服务。

本环境已验证 Node 服务、构建与 HTTP 流程；**没有可连接的浏览器，未验证默认浏览器自动打开、视觉效果和双击脚本完整交互**。macOS `.command` 已提供但未在 macOS 实机测试。详见 [测试结果](TEST_RESULTS.md)。

## 命令行

在项目根目录执行：

```powershell
npm ci
Copy-Item .env.example .env
npm run dev
```

开发访问 **http://127.0.0.1:5173**，API 默认 3000，统一命令同时启动前后端。开发端口 5173 被占用时直接提示。根目录 `.env` 的 PORT 同时用于 API 与 Vite 代理。

日常使用：

```powershell
npm run build
npm start
```

构建后 Node 提供网页和 API，使用同一个本机地址。`node scripts/launcher.mjs start` 额外提供环境检查和自动打开浏览器；`install`、`configure` 对应安装与配置入口。端口占用时不会结束未知进程，在 `.env` 中修改 `PORT` 即可。

macOS 可先运行 `chmod +x *.command`，再双击对应脚本；也可以直接用上述 npm 命令（创建配置用 `cp .env.example .env`）。Linux 可使用 npm 命令，自动打开浏览器脚本目前只针对 Windows/macOS。

首次启动先注册或登录；已有数据继承见升级文档。首次安装需要联网下载依赖。之后普通启动、导入、学习、FSRS、统计、备份恢复均在本机运行。界面使用系统字体与打包后的 Lucide 图标，无外部字体或 CDN；发音取决于浏览器及系统是否安装英语语音包。

## 开始学习

- 在“我的词库”创建词库，或在“导入单词”的预览步骤创建目标词库。
- 上传 `.xlsx`、UTF-8 `.csv` 或 `.txt`，确认字段映射和目标词库后导入。导入前不会修改数据库，也不会自动调用 AI。
- 首页“开始今日学习”，或“今日计划”选择模式。显示答案后选择 Again / Hard / Good / Easy，自评才写入一次正式复习。
- 选择题需有本词中文释义，以及另外至少三个不同的中文释义；不足时提示并允许按卡片自评。中译英需有中文释义。听音使用发音按钮后输入答案。
- 选择、拼写、听音的自动检查仅提供反馈，最终 FSRS 评级由本人选择。点击“显示答案”而未作答不计入答题正确率。
- “错词专项”是额外练习，不写正式复习、不调整到期日期。正式学习会自动优先安排到期困难词。
- 开始学习后刷新或重启，重新计算当前待学队列；只有已正式提交的评价算完成。未评价的卡片仍在队列。

## 导入字段与重复规则

示例均为项目原创： [CSV](apps/web/public/examples/vocabulary.csv)、[Excel](apps/web/public/examples/vocabulary.xlsx)、[TXT](apps/web/public/examples/vocabulary.txt)。页面提供 CSV 下载，其他示例位于 public/examples，也可直接访问 `/examples/vocabulary.xlsx` 和 `/examples/vocabulary.txt`。

| 英文表头    | 中文表头        | 说明                                       |
| ----------- | --------------- | ------------------------------------------ |
| word        | 英文单词 / 单词 | 必需；仅含英语字母、空格、撇号、连字符、点 |
| zh          | 中文释义 / 释义 | 可空                                       |
| en          | 英文释义        | 可空                                       |
| phonetic    | 音标            | 可空                                       |
| pos         | 词性            | 可空                                       |
| example     | 英文例句        | 可空                                       |
| translation | 中文例句翻译    | 可空                                       |
| tags        | 单词标签 / 标签 | 自定义文本标签                             |
| notes       | 个人备注 / 备注 | 自定义笔记                                 |

Excel 读取第一个工作表；第一行识别到字段名时作为表头，否则作为数据。TXT 每行一个词，支持逗号或制表符分列。CSV 用标准双引号包裹带逗号内容。文件最多 20 MB、20,000 行，已测试 3000 行 Excel。预览显示前 8 行；导入报告列出成功、重复跳过、无效数量与数据行原因。

英文单词首尾空格去除，大小写不敏感。**同一个账号内，一个单词只有一张记忆卡片**，加入多个词库仅增加关联。已存在的单词保留原释义、笔记与 FSRS 状态，不自动覆盖；需修改时使用编辑。

删除词库仅删除词库和关联，单词仍在“全部词库”，全局学习也能继续安排这些单词。删除单词会永久删除全部关联、卡片和其复习日志，历史统计随之减少；页面有确认提示，已消耗的当天新词配额不会退还。需要恢复词汇时可重新导入此前导出的 CSV；完整学习状态恢复由管理员处理。

## 计划与统计规则

- 默认每天 20 新词、30 分钟，时间是软目标。首次**真正提交学习评价**的学习日最多 80 个新词；之后每天最多 200，可设置 1–200 的目标。想继续时可继续评价，超过目标仍遵守硬上限。
- 首日可自行按每 20 个词分组休息，系统当前使用连续队列，没有强制分组计时器。
- 所有词库共享新词额度。再次复习同一单词不消耗新词额度；额度在事务中持久化，多个标签页不会额外发放。
- 优先顺序：到期重新学习词 → 逾期复习 → 当天已到期复习 → 新词。当天尚未到具体时间的卡片等待到期；刷新队列即可获取同日再次到期的词。未完成的卡片不清除，隔天依然到期。
- 预留时间预算 10%；初始估算新词 45 秒、旧词 20 秒，之后按历史有效作答时间均值估计。建议新词数量扣除已学目标与已用时间，复习多时减少建议。
- 学习时区保存在设置，开始正式学习后固定，避免改时区重新发放。系统日期倒退不会退回配额日期；检测到实际评价时间回拨会拒绝提交，校正时间后再学。人为把系统时钟拨到未来无法被纯离线服务可靠识别，应使用正确的系统时间。
- 今日新词是首次学习的不同单词数；旧词复习是非首次正式评价次数；另显示不同词数和总作答数。选择/拼写/听音的答题正确率与卡片评级分开。
- 有效时间只在学习页面可见且最近 60 秒有交互时累计，每次正式提交最多记录 120 秒。额外练习目前不计入正式学习时长。没有答题记录时正确率显示 `—`。
- 困难词包括 FSRS lapses>0、曾 Again 或有正式答错记录的词。词库“掌握”是已复习至少 5 次且 FSRS lapses=0 的展示指标，不是考试成绩。未来预测按 UTC 到期日期聚合，日常配额按学习时区处理。
- 修改目标保持率只影响之后的 FSRS 计算，不会由 AI 或设置批量重排已有卡片。

## 数据、备份与恢复

默认数据库：`项目根目录/data/vocabflow.sqlite`。配置 `DATA_DIR` 可更换；相对路径始终相对于项目根目录，绝不按终端工作目录解析。各账号文件路径见运维文档，设置页不展示服务器路径。`.env` 同样固定从项目根目录读取。

每次正式复习在同一 SQLite 事务内校验版本、调用 **ts-fsrs**、保存完整卡片 JSON、完整 FSRS 日志、学习时长、日期与配额。唯一事件 ID 避免重复提交；卡片版本防止旧标签页覆盖；服务重启/恢复后旧页面必须重新加载卡片。发音或 AI 失败不会回滚已经保存的学习。

网页“设置与导出”提供“下载词汇 CSV”，导出当前账号全部单词和中文释义，仅含 `word`、`zh` 两列。空词库也有两列表头；不导出账号信息、AI 配置、学习记录或记忆进度。文件可通过“导入词库”重新导入。页面不再提供完整数据库备份/恢复入口。

管理员运维保留完整备份/恢复接口。完整备份使用 Node SQLite 在线备份 API 获取一致快照，包含尚在 WAL 中的已提交数据；备份保存在 `BACKUP_DIR`（默认 `backups/`）。

管理员恢复完整 `.sqlite` 时：校验数据库完整性、表、迁移版本、设置、外键和卡片状态 → 自动生成 `before-restore-*.sqlite` → 停止其他接口写入 → 替换并执行迁移 → 更新学习空间版本。失败会保留/回退原数据。恢复上传上限 250 MB，恢复时请关闭其他学习标签页。备份包含个人学习内容，请妥善保存。

**普通 CSV 只用于查看或交换词表/日志，不足以恢复 FSRS 全部状态。** 换电脑或回退应用前使用完整备份，不要在运行时只复制 `vocabflow.sqlite` 而遗漏 WAL。

SQL 迁移在 `database/migrations`，按文件名逐个事务执行，记录在 migrations 表；不会启动时清库。后续改表需新增迁移，不修改已经发布的迁移。Git 回退源码不回退数据库；不兼容回退应先保存当前完整备份，再使用旧版本及其对应旧备份。

## 个人 AI 配置

登录后在“设置与备份 → 个人 AI 服务”填写自己的 OpenAI 兼容 Base URL、模型名称和 API Key，点击“保存 AI 配置”，再开启 AI 功能并保存设置。密钥加密存储，不回显；留空保留已有密钥，可主动清除。配置保存立即生效，无需重启。服务器 `.env` 的旧 AI 密钥不再提供给各账号。

在词库列表或学习卡片点击“AI 补全资料”，预览、编辑后保存中文释义、词性、例句、翻译和用法说明；仅填空白字段，不修改 FSRS。AI 解释及学习建议按当前账号缓存，每账号有独立限额。未配置 AI 时，核心学习正常工作。

学习空间完整备份不含账号凭据和 AI 密钥。管理员恢复须额外保留账号库及其加密密钥，详细文件路径与迁移步骤见 [运维文档](docs/deploy/multi-user-login.md)。

在另一台电脑：安装 Node 24 → 克隆源码仓库 → `npm ci` → 从 `.env.example` 创建 `.env` → `npm run build` → 启动 → 注册登录 → 导入词汇 CSV；需要完整学习状态时由管理员按运维文档迁移。**代码仓库不包含个人学习数据**。

## 常见问题与当前边界

- Node 找不到：安装 Node 24 LTS 后重新打开终端；`node -v` 确认。旧版 Node 不支持本项目所用 SQLite API。
- 端口占用：关闭自己此前开的启动窗口，或配置 PORT。不会自动终止其他程序。
- 页面无法访问：服务必须正在运行；日常方式先构建。仅监听 127.0.0.1，手机和局域网不能访问。
- 没有英语声音：先安装系统英语语音包、重新打开浏览器；语音不可用时切换卡片模式。部分浏览器语音仍可能需要联网，优先选本机语音。
- 显示卡片版本过期：可能在另一标签页已作答，或服务重启/恢复过；点击重新加载队列。提交失败时不要改换评级重试，先重试同一评级或重载。
- 时间回拨：检查系统时间。第一天的 80 上限不会被刷新或重启重置。
- 大词库：列表显示前 500 条搜索结果，搜索可定位其余词，学习和导出均使用全部单词。
- AI 未配置：普通学习正常；按上面的服务端步骤配置后再主动调用。
- 不包含云部署、账号、多用户、同步、独立后台或跨设备服务。真实浏览器验收、macOS 实机验证、真实 AI 调用和实际重启电脑后的人工验证仍待执行；服务进程重启持久化已自动测试。
