# Cloudflare + D1 部署需求

来源：用户要求替换 Google Cloud 部署，采用 Cloudflare + D1；用户明确选择只导入单词和释义、重新注册账号。

- Workers 同域提供 React 静态页面与 API，通过 HTTPS 访问；不依赖 Google Cloud、系统进程或本地 SQLite 文件。
- 保留注册、登录、退出、修改密码、个人 AI 配置、导入导出、词库、FSRS、多学习模式和统计。
- D1 全部业务数据按账号隔离，跨表关联不可跨账号；写入必须考虑多个 Worker 实例并发，复习幂等、版本校验与配额均持久化。
- 新站空数据库；用户自行注册并通过 CSV 导入原单词和中文释义，不迁移旧账号、AI Key、学习进度和复习日志。
- 个人 AI Key 加密入库，主密钥用 Worker Secret；API 不返回密钥；用户可自行填写 Base URL、模型名及自己的 Key，不设置域名白名单、地址或 AI 调用次数限制。
- 设置页仅导出 word、zh 两列 CSV；不提供完整 SQLite 备份/恢复接口，不暴露服务器路径。
- 使用独立部署分支，不改变仍在运行的旧 Google Cloud 服务；旧云资源关闭/删除由用户决定。
- 提供 Wrangler 配置、D1 迁移、可复用部署说明、本地开发与真实 workerd/D1 集成测试；创建线上资源并验证新站，保留代码 PR 供审阅。
