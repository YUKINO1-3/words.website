# 内置词库

用户要求：除了自行上传 CSV，应用应提供内置词库；首批主要面向雅思和学术英语。通用功能需可向源仓库贡献，同时能在个人 Cloudflare 站点部署。

- 提供雅思常用词（ECDICT IELTS 标签，5040 词）、NAWL 1.2 学术核心词（957 词）和 NGSL 1.2 基础高频词（2809 词），全部附中文释义。
- 来源固定版本、校验值、作者和再分发许可随包保存。NAWL/NGSL 衍生数据遵循 CC BY-SA 4.0；ECDICT 部分保留 MIT 许可。内置不表示考试机构官方大纲。
- 首页和导入页可进入词库目录；我的词库页展示内置词库、来源、数量、样例，可预览及添加。
- 使用现有词库/导入接口，无额外后端或迁移要求，不自动调用 AI。数据由应用静态资源提供，不在运行时访问第三方数据源。
- 添加到个人学习空间；已有同名单词保留内容和记忆状态，重复添加复用同名词库并跳过已有关联。
- 每批最多 1000 词，支持超过单次 3000 词的内置合集。显示进度，失败后已有批次保留，再次添加能继续补齐。
- 页面卸载（含退出账号）后不发起后续写请求，不把旧任务带到另一账号。
- 保留原有 Excel/CSV/TXT 上传流程；离线本地部署只要静态文件已安装即可使用内置数据。
